# net-watch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build net-watch so it answers two questions for any web app: *is the user really online?* and *how good is the connection?* (quality band, latency, throughput, link info). It ships as a zero-dependency core plus React / Vue / Angular adapters, exactly as specified in `docs/architecture.md` and `docs/adapters.md`.

**Architecture:** One ESM package with subpath exports. The plan builds pure modules first (`probe.ts`, `metrics.ts`). Next comes the watcher that owns the state (`watcher.ts`), in two steps: first browser signals, `report()` and metrics; then probing with backoff and the opt-in heartbeat. After that come helpers that use only the public API (`fetch.ts`, `banner.ts`), then ~10-line adapters.

**Tech Stack:** pnpm, TypeScript 7 (`@tsconfig/strictest`), tsdown, Vitest 4 browser mode + Playwright (chromium, firefox, webkit), Vite playground.

## Global Constraints

- The contract is `docs/architecture.md`, adapters follow `docs/adapters.md`, and invariants are in `AGENTS.md`. On conflict, those docs win over this plan.
- Core (`src/watcher.ts`, `probe.ts`, `metrics.ts`, `fetch.ts`, `banner.ts`, `index.ts`) has zero runtime dependencies. `probe` and `metrics` are internal; `src/index.ts` never re-exports them.
- Frameworks are optional peers: `react >=18`, `vue >=3.3`, `@angular/core >=17`, each with `peerDependenciesMeta.<name>.optional: true`.
- Browser floor: Chrome/Edge 90, Firefox 90, Safari/iOS 15. tsdown `target: 'es2020'`.
- SSR-safe: without `window`, state is `online: true`, `quality: 'unknown'`, every metric `undefined`, `saveData: false`.
- Immutable state; listeners fire only when a field changes after rounding (`rtt` to 50 ms; `downlink` to 0.1 Mbps, whole Mbps from 10 up).
- Unknown is `undefined`, never a guess.
- Online and idle sends zero requests unless `heartbeat` is set.
- Package `exports` is generated by tsdown (`exports: true`). Never hand-edit it.
- Test commands: `pnpm vitest run <files>` runs every test in chromium, firefox and webkit, so reported counts are tests × 3. Also `pnpm typecheck` and `pnpm build`.

```ts
/** One HEAD request to `url`. Resolves to the round-trip time in ms, or null on network error or timeout. */
export async function probe(url: string, timeout: number): Promise<number | null> {
  // AbortController + setTimeout instead of AbortSignal.timeout, which needs Safari 16.
  const controller = new AbortController()
  const timer = setTimeout(() => controller.abort(), timeout)
  const start = performance.now()
  try {
    await fetch(url, { method: 'HEAD', mode: 'no-cors', cache: 'no-store', signal: controller.signal })
    return performance.now() - start
  } catch {
    return null
  } finally {
    clearTimeout(timer)
  }
}
```

`src/metrics.ts`:

```ts
export type Quality = 'excellent' | 'good' | 'fair' | 'poor' | 'unknown'
export type EffectiveType = 'slow-2g' | '2g' | '3g' | '4g'
export type ConnectionType = 'bluetooth' | 'cellular' | 'ethernet' | 'wifi' | 'wimax' | 'none' | 'other' | 'unknown'
/** Upper smoothed-RTT bounds in ms for excellent, good and fair; anything slower is poor. */
export type RttBounds = readonly [excellent: number, good: number, fair: number]

type Band = Exclude<Quality, 'unknown'>
type NetworkInformationLike = EventTarget & {
  rtt?: number
  downlink?: number
  effectiveType?: EffectiveType
  type?: ConnectionType
  saveData?: boolean
}

const ALPHA = 0.3
const IMPROVE_RATIO = 0.8
const MIN_TRANSFER_BYTES = 50_000
const RANK: Record<Band, number> = { excellent: 0, good: 1, fair: 2, poor: 3 }

/** Exponentially weighted moving average; the first sample seeds it. */
export const ewma = (prev: number | undefined, sample: number): number =>
  prev === undefined ? sample : prev * (1 - ALPHA) + sample * ALPHA

function bandOf(rtt: number, [excellent, good, fair]: RttBounds, scale = 1): Band {
  if (rtt < excellent * scale) return 'excellent'
  if (rtt < good * scale) return 'good'
  if (rtt < fair * scale) return 'fair'
  return 'poor'
}

/** Degrade as soon as a bound is crossed; improve only below 0.8 × the bound, so quality does not flap. */
export function classify(rtt: number | undefined, prev: Quality, bounds: RttBounds): Quality {
  if (rtt === undefined) return 'unknown'
  const plain = bandOf(rtt, bounds)
  if (prev === 'unknown' || RANK[plain] > RANK[prev]) return plain
  const strict = bandOf(rtt, bounds, IMPROVE_RATIO)
  return RANK[strict] < RANK[prev] ? strict : prev
}

export const roundRtt = (ms: number): number => Math.round(ms / 50) * 50

export const roundDownlink = (mbps: number): number => (mbps < 10 ? Math.round(mbps * 10) / 10 : Math.round(mbps))

/** navigator.connection, which only Chromium ships. */
export const connection = (): NetworkInformationLike | undefined =>
  typeof navigator === 'undefined'
    ? undefined
    : (navigator as Navigator & { connection?: NetworkInformationLike }).connection

/** Chromium-only link info; undefined (saveData false) elsewhere. A zero estimate means "no estimate". */
export function connectionInfo() {
  const c = connection()
  return {
    rtt: c?.rtt || undefined,
    downlink: c?.downlink || undefined,
    effectiveType: c?.effectiveType,
    type: c?.type,
    saveData: c?.saveData ?? false,
  }
}

/** Mbps from one Resource Timing entry; undefined for cached, tiny or opaque (no Timing-Allow-Origin) responses. */
export function throughputOf(
  entry: Pick<PerformanceResourceTiming, 'transferSize' | 'responseStart' | 'responseEnd'>,
): number | undefined {
  const ms = entry.responseEnd - entry.responseStart
  if (entry.transferSize < MIN_TRANSFER_BYTES || ms <= 0) return undefined
  return (entry.transferSize * 8) / ms / 1000
}

/** Feeds a throughput sample for every useful resource the page loads, page-load assets included. */
export function observeThroughput(onSample: (mbps: number) => void): () => void {
  if (typeof PerformanceObserver === 'undefined') return () => {}
  const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries() as PerformanceResourceTiming[]) {
      const mbps = throughputOf(entry)
      if (mbps !== undefined) onSample(mbps)
    }
  })
  observer.observe({ type: 'resource', buffered: true })
  return () => observer.disconnect()
}
```

```ts
import {
  classify,
  connection,
  connectionInfo,
  ewma,
  observeThroughput,
  roundDownlink,
  roundRtt,
  type ConnectionType,
  type EffectiveType,
  type Quality,
  type RttBounds,
} from './metrics'

export type { ConnectionType, EffectiveType, Quality, RttBounds } from './metrics'

export interface NetworkState {
  online: boolean
  /** Date.now() of the last online/offline flip. */
  since: number
  /** Band over smoothed RTT; every browser once sampled. */
  quality: Quality
  /** Smoothed RTT in ms, rounded to 50. */
  rtt: number | undefined
  /** Smoothed throughput in Mbps (Resource Timing; Chromium hint). */
  downlink: number | undefined
  /** Chromium only. */
  effectiveType: EffectiveType | undefined
  /** Chrome on Android / ChromeOS only. */
  type: ConnectionType | undefined
  /** Chromium only; false elsewhere. */
  saveData: boolean
}

export type NetworkListener = (state: NetworkState, prev: NetworkState) => void

export interface WatcherOptions {
  /** Quality bands over smoothed RTT, ms. Default [150, 400, 1400]. */
  rttBounds?: RttBounds
  onOnline?: (state: NetworkState) => void
  onOffline?: (state: NetworkState) => void
}

export interface NetworkWatcher {
  /** Same object reference until a field changes. */
  getState: () => NetworkState
  /** Returns an unsubscribe function. */
  subscribe: (listener: NetworkListener) => () => void
  /** Decide now. */
  check: () => Promise<NetworkState>
  /** Evidence from outside: real requests, a service worker, the native OS. */
  report: (ok: boolean, rtt?: number) => void
  /** Resolves when online (immediately if already online). */
  waitForOnline: () => Promise<NetworkState>
  /** Removes every listener, observer and timer. */
  destroy: () => void
}

const isBrowser = typeof window !== 'undefined'
const DEFAULT_BOUNDS: RttBounds = [150, 400, 1400]
const FIELDS = ['online', 'quality', 'rtt', 'downlink', 'effectiveType', 'type', 'saveData'] as const

export function createNetworkWatcher(options: WatcherOptions = {}): NetworkWatcher {
  const { rttBounds = DEFAULT_BOUNDS, onOnline, onOffline } = options
  const listeners = new Set<NetworkListener>()
  const info = connectionInfo()
  const startOnline = isBrowser ? navigator.onLine : true
  // Smoothed, unrounded averages; the state carries rounded values.
  let rttAvg = startOnline ? info.rtt : undefined
  let downlinkAvg = startOnline ? info.downlink : undefined

  const metrics = (prevQuality: Quality) => ({
    quality: classify(rttAvg, prevQuality, rttBounds),
    rtt: rttAvg === undefined ? undefined : roundRtt(rttAvg),
    downlink: downlinkAvg === undefined ? undefined : roundDownlink(downlinkAvg),
  })

  let state: NetworkState = {
    online: startOnline,
    since: Date.now(),
    ...metrics('unknown'),
    effectiveType: info.effectiveType,
    type: info.type,
    saveData: info.saveData,
  }

  const update = (patch: Partial<NetworkState>) => {
    const prev = state
    const next = { ...prev, ...patch }
    if (FIELDS.every((key) => next[key] === prev[key])) return
    if (next.online !== prev.online) next.since = Date.now()
    state = next
    if (next.online !== prev.online) (next.online ? onOnline : onOffline)?.(next)
    for (const listener of listeners) listener(next, prev)
  }

  const goOnline = (sample?: number) => {
    if (sample !== undefined) rttAvg = ewma(rttAvg, sample)
    update({ online: true, ...metrics(state.quality) })
  }

  const goOffline = () => {
    rttAvg = undefined
    downlinkAvg = undefined
    update({ online: false, ...metrics('unknown') })
  }

  const sampleDownlink = (mbps: number) => {
    if (!state.online) return
    downlinkAvg = ewma(downlinkAvg, mbps)
    update(metrics(state.quality))
  }

  const check = async () => {
    if (isBrowser) {
      if (navigator.onLine) goOnline()
      else goOffline()
    }
    return state
  }

  const report = (ok: boolean, sample?: number) => {
    if (ok) goOnline(sample)
  }

  const subscribe = (listener: NetworkListener) => {
    listeners.add(listener)
    return () => {
      listeners.delete(listener)
    }
  }

  const waitForOnline = () =>
    state.online
      ? Promise.resolve(state)
      : new Promise<NetworkState>((resolve) => {
          const off = subscribe((s) => {
            if (s.online) {
              off()
              resolve(s)
            }
          })
        })

  const recheck = () => {
    void check()
  }
  const handleOffline = () => goOffline()
  const handlePageShow = (e: PageTransitionEvent) => {
    if (e.persisted) recheck()
  }
  const handleVisibility = () => {
    if (document.visibilityState === 'visible') recheck()
  }
  const conn = connection()
  const handleConnection = () => {
    const c = connectionInfo()
    if (state.online) {
      if (c.rtt !== undefined) rttAvg = ewma(rttAvg, c.rtt)
      if (c.downlink !== undefined) downlinkAvg = ewma(downlinkAvg, c.downlink)
    }
    update({ ...metrics(state.quality), effectiveType: c.effectiveType, type: c.type, saveData: c.saveData })
  }

  let stopThroughput = () => {}
  if (isBrowser) {
    window.addEventListener('online', recheck)
    window.addEventListener('offline', handleOffline)
    window.addEventListener('pageshow', handlePageShow)
    document.addEventListener('visibilitychange', handleVisibility)
    conn?.addEventListener('change', handleConnection)
    stopThroughput = observeThroughput(sampleDownlink)
  }

  return {
    getState: () => state,
    subscribe,
    check,
    report,
    waitForOnline,
    destroy() {
      if (isBrowser) {
        window.removeEventListener('online', recheck)
        window.removeEventListener('offline', handleOffline)
        window.removeEventListener('pageshow', handlePageShow)
        document.removeEventListener('visibilitychange', handleVisibility)
        conn?.removeEventListener('change', handleConnection)
      }
      stopThroughput()
      listeners.clear()
    },
  }
}

export const sharedWatcher = (): NetworkWatcher => (shared ??= createNetworkWatcher())
```

```ts
  }
  const handleOffline = () => goOffline()
  const handlePageShow = (e: PageTransitionEvent) => {
    if (e.persisted) recheck()
  }
  const handleVisibility = () => {
    if (document.visibilityState === 'visible') recheck()
  }
  const conn = connection()
  const handleConnection = () => {
    const c = connectionInfo()
    if (state.online) {
      if (c.rtt !== undefined) rttAvg = ewma(rttAvg, c.rtt)
      if (c.downlink !== undefined) downlinkAvg = ewma(downlinkAvg, c.downlink)
    }
    update({ ...metrics(state.quality), effectiveType: c.effectiveType, type: c.type, saveData: c.saveData })
  }

  let stopThroughput = () => {}
  let heartbeatTimer: ReturnType<typeof setInterval> | undefined
  if (isBrowser) {
    window.addEventListener('online', recheck)
    window.addEventListener('offline', handleOffline)
    window.addEventListener('pageshow', handlePageShow)
    document.addEventListener('visibilitychange', handleVisibility)
    conn?.addEventListener('change', handleConnection)
    stopThroughput = observeThroughput(sampleDownlink)
    if (pingUrl && heartbeat) {
      heartbeatTimer = setInterval(() => {
        if (state.online && document.visibilityState === 'visible') recheck()
      }, heartbeat)
    }
    recheck() // startup is a suspect
  }

  return {
    getState: () => state,
    subscribe,
    check,
    report,
    waitForOnline,
    destroy() {
      if (isBrowser) {
        window.removeEventListener('online', recheck)
        window.removeEventListener('offline', handleOffline)
        window.removeEventListener('pageshow', handlePageShow)
        document.removeEventListener('visibilitychange', handleVisibility)
        conn?.removeEventListener('change', handleConnection)
      }
      clearInterval(heartbeatTimer)
      stopRetry()
      stopThroughput()
      listeners.clear()
    },
  }
}

let shared: NetworkWatcher | undefined
/** Lazily created default watcher; adapters use it when no watcher is passed. */
export const sharedWatcher = (): NetworkWatcher => (shared ??= createNetworkWatcher())
```

```ts
import type { NetworkWatcher } from './watcher'

/** Wraps fetch so real requests feed the watcher: responses prove online, network errors raise suspicion. */
export function watchFetch(watcher: NetworkWatcher, baseFetch: typeof fetch = fetch): typeof fetch {
  return async (input, init) => {
    const start = performance.now()
    try {
      const res = await baseFetch(input, init)
      // fetch resolves at headers, so this is time-to-headers regardless of body size.
      watcher.report(true, performance.now() - start)
      return res
    } catch (err) {
      // Network failures are a TypeError in every engine; the message differs, so never match on it.
      if (err instanceof TypeError) watcher.report(false)
      throw err
    }
  }
}
```

```ts
import type { NetworkListener, NetworkState, NetworkWatcher } from './watcher'

export interface BannerOptions {
  /** Default 'You are offline'. */
  offlineText?: string
  /** Default 'Back online'. */
  onlineText?: string
  /** Shown while quality is 'poor'. Unset = never show it. */
  slowText?: string
  /** Default 'bottom'. */
  position?: 'top' | 'bottom'
  /** ms the back-online message stays visible. Default 3000. */
  hideAfter?: number
  /** Default document.body. */
  container?: HTMLElement
}

type View = 'offline' | 'slow' | 'online'

// :where() keeps specificity at 0, so any user rule on .netwatch-banner wins.
const CSS = `
:where(.netwatch-banner){position:fixed;left:0;right:0;z-index:9999;padding:8px 16px;text-align:center;font:14px/1.4 system-ui,sans-serif;color:#fff}
:where(.netwatch-banner[data-position=top]){top:0}
:where(.netwatch-banner[data-position=bottom]){bottom:0}
:where(.netwatch-banner[data-state=offline]){background:#c62828}
:where(.netwatch-banner[data-state=slow]){background:#f9a825;color:#1a1a1a}
:where(.netwatch-banner[data-state=online]){background:#2e7d32}
`

export function createBanner(watcher: NetworkWatcher, options: BannerOptions = {}): { destroy: () => void } {
  const {
    offlineText = 'You are offline',
    onlineText = 'Back online',
    slowText,
    position = 'bottom',
    hideAfter = 3000,
    container = document.body,
  } = options
  const texts: Record<View, string> = { offline: offlineText, slow: slowText ?? '', online: onlineText }

  if (!document.getElementById('netwatch-style')) {
    const style = document.createElement('style')
    style.id = 'netwatch-style'
    style.textContent = CSS
    document.head.append(style)
  }

  const el = document.createElement('div')
  el.className = 'netwatch-banner'
  el.setAttribute('role', 'status')
  el.dataset['position'] = position
  el.hidden = true
  container.append(el)

  let timer: ReturnType<typeof setTimeout> | undefined
  const viewOf = (s: NetworkState): View =>
    !s.online ? 'offline' : slowText !== undefined && s.quality === 'poor' ? 'slow' : 'online'

  const show = (view: View) => {
    clearTimeout(timer)
    el.dataset['state'] = view
    el.textContent = texts[view]
    el.hidden = false
    if (view === 'online') timer = setTimeout(() => (el.hidden = true), hideAfter)
  }

  const render: NetworkListener = (state, prev) => {
    const view = viewOf(state)
    const before = viewOf(prev)
    if (view === before) return
    if (view === 'online' && before === 'slow') {
      clearTimeout(timer)
      el.hidden = true
      return
    }
    show(view)
  }

  const off = watcher.subscribe(render)
  const initial = viewOf(watcher.getState())
  if (initial !== 'online') show(initial)

  return {
    destroy() {
      off()
      clearTimeout(timer)
      el.remove()
    },
  }
}
```

````markdown
# net-watch

Answers two questions for any web app:

1. **Is the user really online?** Not just "Wi-Fi is on", but actually able to reach your server.
2. **How good is the connection?** Quality band, latency, throughput, and the link info the browser exposes.

Zero-dependency core, thin adapters for React, Vue and Angular. Works in Chrome/Edge 90+, Firefox 90+ and Safari/iOS 15+.

```bash
pnpm add net-watch

## Core

```ts
import { createBanner, createNetworkWatcher, watchFetch } from 'net-watch'

const watcher = createNetworkWatcher({
  pingUrl: '/ping', // optional, see below
  heartbeat: 60_000, // optional: also check while the app is idle
  onOffline: () => console.log('offline'),
  onOnline: () => console.log('back online'),
})

watcher.subscribe((state) => console.log(state.online, state.quality, state.rtt))
export const api = watchFetch(watcher) // use instead of fetch: real requests become free signals
await watcher.waitForOnline() // e.g. before retrying
createBanner(watcher, { offlineText: 'Mất kết nối mạng', onlineText: 'Đã kết nối lại', slowText: 'Mạng chậm' })
```

### State

| Field | Meaning | Available in |
|---|---|---|
| `online` | really online | every browser |
| `since` | time of the last online/offline flip | every browser |
| `quality` | `excellent` < 150 ms · `good` < 400 · `fair` < 1400 · `poor` · `unknown` | every browser, once a sample exists |
| `rtt` | smoothed latency, ms (rounded to 50) | every browser, once a sample exists |
| `downlink` | smoothed throughput, Mbps | Chrome/Edge, Firefox, Safari 16.4+ |
| `effectiveType` | `slow-2g` / `2g` / `3g` / `4g` | Chrome/Edge |
| `type` | `wifi` / `cellular` / … | Chrome on Android, ChromeOS |
| `saveData` | user enabled data saver | Chrome/Edge |

A value the browser cannot provide is `undefined`, never a guess. Signal strength (Wi-Fi bars, dBm) is not exposed to web pages by any browser.

### How detection works

1. **Browser signals**: `navigator.onLine`, the `online`/`offline` events, tab visible, bfcache restore. Free and instant, but `online: true` only means a network interface is up.
2. **Real requests** through `watchFetch` (or `watcher.report(ok, rtt)`). A response proves you are online and measures latency.
3. **A probe to `pingUrl`**, sent only on suspicion or while offline (backoff 2 s → 30 s), plus every `heartbeat` ms if you opt in. Without `heartbeat`, online and idle sends nothing.

Without `pingUrl` you get layers 1–2: unplugged cables and Wi-Fi off are detected, but "connected but no internet" is not.

### Choosing `pingUrl`

Use a same-origin HTTPS route that:
- answers `HEAD` with `204` and `Cache-Control: no-store`;
- needs no auth;
- is excluded from any service-worker cache.

```nginx
location = /ping { add_header Cache-Control no-store; return 204; }
```

No backend? `https://www.gstatic.com/generate_204` works, with three caveats:
- It is blocked in some regions and corporate networks, so users there would always look offline.
- It sends every user's IP to Google.
- If you use a CSP, it needs `connect-src https://www.gstatic.com`.
````
