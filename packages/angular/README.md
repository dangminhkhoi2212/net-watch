# @net-watch/angular

Angular signal for net-watch: injectNetworkStatus().

```sh
pnpm add @net-watch/core @net-watch/angular
```

```ts
import { injectNetworkStatus } from '@net-watch/angular'

status = injectNetworkStatus() // status().online
```

Docs: https://github.com/dangminhkhoi2212/net-watch#readme
